# Licensing

Mansooba is licensed under the [GNU Affero General Public License v3.0](../../LICENSE) (`AGPL-3.0-only`). The owner keeps the option of offering a commercial licence later; none is offered today. The decision and its trade-offs are ADR-035 in the documentation repository.

## What the licence means for you

- **Use, study, change, share:** all allowed under the AGPL.
- **Run a modified version as a network service:** you must offer your users the source of your modified version (AGPL section 13). Set `SOURCE_CODE_URL` to where it is published.
- **Run it unmodified:** keep `SOURCE_CODE_URL` at its default.

## Source and licence notice in the app

Every page shows "Source code", "AGPL-3.0" and the version. The data comes from the public endpoint `GET /api/v1/about`.

| Setting | Default | Rule |
|---|---|---|
| `SOURCE_CODE_URL` | `https://github.com/sharique/mansooba` | Absolute `http` or `https` URL, no credentials, at most 2048 characters. An invalid value stops the server at start-up with a clear log line. |

If the endpoint cannot be reached the page still shows the default repository link and the licence name.

## Contributing code

Outside code contributions need a one-time signature of [CLA.md](../../CLA.md), because that is what keeps relicensing possible. The `CLA` check on a pull request comments with the sentence to post; signatures are stored in `signatures/v1/cla.json` on the `cla-signatures` branch. The owner is allowlisted. Issues and ideas need no agreement. See [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Checks that run in CI

| Check | What it enforces |
|---|---|
| `Verify licence statements` (`scripts/check-license-statements.sh`) | `LICENSE` is the verbatim AGPL-3.0 text; `NOTICE`, README, `frontend/package.json` and the Swagger docs agree; the CLA files and workflow are consistent and safe; no document still claims the licence is open or pending |
| `Licences` (`scripts/check-licenses.sh`) | Every shipped Go module, npm package and icon set has an allowed licence. GPL-only, AGPL-only, source-available (SSPL, BUSL) and dependencies lacking a declared licence fail. LGPL-family needs a recorded, component-specific entry in `scripts/licenses/exceptions.txt` |
| `CLA` (`cla.yml`) | Every commit author on a pull request has signed |

Run the first two locally: `scripts/check-license-statements.sh`, `scripts/check-licenses.sh` (the second needs network for `lichen` and `license-checker-rseidelsohn`).

## What ships in the images

Both images contain `LICENSE`, `NOTICE` and `THIRD-PARTY-NOTICES.md` under `/licenses/` and the label `org.opencontainers.image.licenses=AGPL-3.0-only`. `THIRD-PARTY-NOTICES.md` is generated by `scripts/generate-notices.sh` during the image build; it is not committed.

## Adding a dependency

Run `scripts/check-licenses.sh`. If it names your dependency, pick another, or (LGPL-family only) add a reasoned exception for that one component. Never add a blanket rule.
